Implementation Checklist

Week 1-2: Build Phase

  • Design referral program mechanics (double-sided, Rs.100 each)
  • Build unique referral code generation system
  • Create referral tracking and attribution logic
  • Design in-app referral dashboard UI
  • Implement post-booking referral prompt
  • Build share functionality (WhatsApp, SMS, Email)
  • Set up reward distribution system
  • Create leaderboard and gamification features

Week 3: Testing Phase

  • Internal QA testing of referral flow
  • A/B test referral messaging (copy, placement, timing)
  • Test reward distribution and fraud prevention
  • Beta launch with 1,000 power users
  • Collect feedback and iterate

Week 4: Launch Phase

  • Full rollout to all 500K+ users
  • Push notification campaign announcing referral program
  • Email campaign to existing users
  • In-app banners and prompts
  • Set up analytics dashboard for growth team
  • Monitor key metrics and optimize

Ongoing: Optimization

  • Weekly cohort analysis of referral users
  • A/B test reward amounts (Rs.75 vs. Rs.100 vs. Rs.150)
  • Test different prompt timings (immediate vs. 24h delay)
  • Optimize share message copy and creative
  • Launch monthly referral challenges and contests
  • Expand to neighborhood-based leaderboards

Key Success Factors

Why This Will Work for Pronto

  • High-Trust Category: House help requires trust. People trust friends/family recommendations 3x more than ads
  • Existing User Base: 500K+ satisfied users (4.5-star rating) are an untapped distribution channel
  • Double-Sided Rewards: Both referrer and referee benefit, increasing conversion by 2-3x vs. single-sided
  • Competitive Gap: Urban Company and BookMyBai lack structured referral mechanics
  • Viral Potential: House help is a common need in urban India, especially in apartment complexes and gated communities
  • Low CAC: Referral CAC (Rs.150) is 40% lower than paid ads (Rs.250)
  • Higher Retention: Referred users have 55% 30-day retention vs. 35% organic users
  • Compounding Growth: Viral coefficient of 0.36 means exponential user growth over time

Technical Architecture

1
Referral Code Generation

Unique alphanumeric codes (e.g., PRONTO2024) generated per user, stored in database with user_id mapping

2
Attribution Tracking

When new user signs up with code, create referral_attribution record linking referrer_id and referee_id

3
Event Triggers

Listen for booking_completed event. When referee completes first booking, trigger reward distribution

4
Reward Distribution

Add Rs.100 credit to referrer's wallet, send push notification. Referee discount applied at checkout

5
Fraud Prevention

Device fingerprinting, phone number verification, rate limiting (max 50 referrals/day), manual review for suspicious patterns

6
Analytics & Reporting

Track referral_signups, referral_bookings, reward_distributed, viral_coefficient in real-time dashboard
